財富7部曲 PWA

功能
- 多銀行帳戶與用途分類
- 緊急備用金計算
- 財務目標進度
- 每月薪資分配
- IndexedDB 本機永久儲存
- JSON 匯出 / 匯入備份
- Service Worker 離線支援
- 可安裝到手機主畫面

使用方式
1. 把整個資料夾放到 HTTPS 網站空間（例如 GitHub Pages、Netlify、Cloudflare Pages）。
2. 用手機 Safari / Chrome 開啟網址。
3. iPhone：分享 → 加入主畫面。
4. Android：瀏覽器選單 → 安裝應用程式 / 加入主畫面。

注意
- 直接用 file:// 開啟時，PWA 安裝與 Service Worker 通常不會生效。
- IndexedDB 資料只存在目前瀏覽器/裝置。請定期用「匯出備份 JSON」保存副本。
